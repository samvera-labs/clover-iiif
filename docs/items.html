Items

Items replaces Clover 3.x's Slider and the Viewer's thumbnail strip.

Thumbnails of a sequence, as a carousel, a list or a grid.

  • Inside a Clover.Root, Items lists the Root's views (a spread is one item) and selecting one goes there. It is a listbox, and like a radio group the selection follows focus: one tab stop, and the arrow keys, Home and End select as they move (where a held arrow stops, not each page it passes). Enter, Space or a click is a choice, which onSelect reports. The selection follows the pager too. A Collection's members move with the arrows and are chosen with Enter, since each loads a Manifest.
  • On its own, given iiifContent or items, it lists a Collection's members as links to their homepage, as the Slider did.
import * as Clover from "@nulib/clover";
 
<Clover.Root iiifContent={manifestUrl}>
  <Clover.Content />
  <Clover.Items layout="carousel" />
</Clover.Root>;

A Collection

<Clover.Items iiifContent={collectionUrl} />

The carousel is the browser's own scrolling with CSS scroll snapping, so wheel, trackpad, touch and keyboard scrolling all work, and a mouse can drag it. Thumbnails load lazily (loading="lazy"), at the size asked of each image service.

Props

PropTypeDescription
layout"carousel" | "list" | "grid"Default carousel.
iiifContentstring | objectOn its own: a Collection (its members) or a Manifest (its views).
itemsobject[]On its own: IIIF resources to list as they are.
navigation"id" | "homepage"Select (a listbox) or leave (links). Defaults to id for views and homepage for members.
onSelect(item, event) => voidAn item was chosen. On a link, event.preventDefault() keeps the reader on the page.
filterbooleanA search field that narrows the items by label.
headerbooleanOn its own: the resource's label, summary and homepage link. Default true.
thumbnailSizenumberPixels asked for each thumbnail's longer side. Default 200.
renderItem(item, { selected }) => ReactNodeYour own item in place of the figure.
request{ credentials, headers, fetch }On its own. Inside a Root, the Root's.
