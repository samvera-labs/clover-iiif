Map

Map

Looking for the Map of Clover 3.x, @samvera/clover-iiif? It is at Clover 3.x › Map.

Where a IIIF resource is, on a map: its navPlace (opens in a new tab) places, and its georeferenced (opens in a new tab) images warped onto the map by their control points. A Viewer shows it by itself, in a Map tab, whenever the Manifest has places or georeferences. On its own, Map comes from @nulib/clover/map.

import { Map } from "@nulib/clover/map";
import "@nulib/clover/styles.css";
import "maplibre-gl/dist/maplibre-gl.css";
 
<Map iiifContent="https://iiif.io/api/cookbook/recipe/0240-navPlace-on-canvases/manifest.json" />;

What it loads

The map draws with MapLibre GL (opens in a new tab), which comes with Clover. Import its stylesheet beside Clover's.

MapLibre is about 287 kB gzip, and it is downloaded only when a map is first shown: a Viewer whose Manifest has no places never loads it, and one that has loads it when the reader opens the Map tab. The Map tab itself costs a page without a map about 0.6 kB. @nulib/clover/map on its own is about 17 kB before MapLibre, most of it the Root it shares with the rest of Clover.

MapLibre's worker

MapLibre 6 starts its worker from a file beside its own module, and that worker imports a second file by relative path. A bundler that moves or renames MapLibre's files breaks that: the basemap draws, but places and overlays never appear. Next and webpack do. If yours does, serve the worker yourself and tell Clover where, once, for every map (a Viewer's Map tab included), with setMapWorkerUrl; a standalone Map also takes workerUrl:

  • Vite bundles a worker with its imports: import workerUrl from "maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url".
  • Anywhere else, copy maplibre-gl-worker.mjs and maplibre-gl-shared.mjs from node_modules/maplibre-gl/dist/ to the same static folder, and pass the worker's URL.
import { setMapWorkerUrl } from "@nulib/clover";
 
setMapWorkerUrl("/static/maplibre-gl-worker.mjs");

In a Viewer

Inside a Root, Map maps the Root's resource: its places, and the georeferenced image of the view on the stage, following the reader from page to page. Pressing a place names it, and goes to its Canvas.

The Viewer, the templates and any default InformationPanel add a Map tab by themselves when the Manifest, its Collection, a Canvas or an annotation has navPlace or a georeference. Nothing to pass:

<Viewer iiifContent={url} />

Below, the georeferenced Evanston map from Clover's mocks: open the Map tab.

Georeferenced images

A Georeference Extension (opens in a new tab) annotation names points on an image and where each is on the earth. Map reads them from the Canvases' annotation pages, or from georeferences you pass, whether they target a Canvas or an image service.

It draws them the basic way: the best affine (first-order polynomial) fit of the control points, which is exact for three. One image of up to 2048 px, clipped to the annotation's SvgSelector mask, placed by its four corners. The image server must allow CORS, as MapLibre draws with WebGL.

Not drawn: thin-plate spline or higher-order warps, and deep zoom into the overlay. Allmaps (opens in a new tab) does both, and its MapLibre layer is about 422 kB gzip; Clover's overlay is a few kB. A map that needs them can add Allmaps' WarpedMapLayer to the same MapLibre map.

Places

navPlace is read on the Collection, the Manifest, each Canvas, and each loaded annotation, and so is an annotation whose body is GeoJSON (Cookbook 0139 (opens in a new tab)). Points, lines and areas are drawn in the accent color, or in a feature's own simplestyle (opens in a new tab) fill, stroke and marker-color. Each is named by its label, in the reader's language, or by the resource it belongs to.

Properties

PropTypeWhat it does
iiifContentURL or IIIF objectStandalone: a resource to map. Inside a Root, leave it out.
navPlaceGeoJSONPlaces to draw: a FeatureCollection, a Feature or a geometry.
georeferencesannotationsGeoreference Extension annotations to overlay.
overlaybooleanDraw georeferenced images. Default true.
overlayOpacitynumberTheir opacity, 0 to 1. Default 0.75.
styleUrlstringA MapLibre style, used as it is. Default: Clover's relief basemap.
workerUrlstringWhere MapLibre's worker is served from, if your bundler moves it.
scrollZoombooleanZoom with the wheel or trackpad. Default false, so page scroll is not trapped.
onSelect(feature) => voidA place was pressed. Its properties hold title and canvasId.
request{ credentials, headers }Standalone: how to fetch.

Size it with --clover-map-height (default 24rem).

The default basemap is OpenFreeMap's Liberty, keyless, with roads removed and relief from Mapzen's terrain tiles, as 3.x's Map draws it. Wheel zoom is off; the zoom buttons, double-click and pinch all work.

navPlaceOf, georeferencesOf, readGeoreference, affineTransform, cornersOf and boundsOf are exported from @nulib/clover/map too, for a map of your own.
