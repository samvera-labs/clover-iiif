# Templates

<Callout type="info">
  **In development.** Part of Clover 4.x, `@nulib/clover`, which is not
  released.
</Callout>

Ready-made layouts, each built only from the parts `@nulib/clover` exports. Load one as
it is, or copy its source (`packages/clover/src/templates/<name>/`) into your app and
change it: nothing in a template is private.

```jsx
import * as Templates from "@nulib/clover/templates";
import "@nulib/clover/styles.css";
import "@nulib/clover/templates.css";

<Templates.Classic iiifContent={url} />;
```

Templates come from their own entry, `@nulib/clover/templates`, with their own
stylesheet, `@nulib/clover/templates.css`, so an app that does not use them carries
neither. Every template takes the `Clover.Root` props: `request`, `canvasId`,
`annotations`, `onContentStateChange` and the rest.
